## Versioning Guide

- **0.x.y** = Pre-release / development
- **1.0.0** = Public gallery + Admin CRUD + D1 พร้อมใช้งานจริง
- **1.x** = ปรับปรุงและเพิ่มฟีเจอร์ Phase 1
- **2.0.0** = มี X Sync / R2 / Analytics เต็มรูปแบบ
